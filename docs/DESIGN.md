# Arbor 设计文档

> 一个兼顾美观与效率的 macOS 原生文件管理器。目标：替代访达的日常使用，把 QSpace Pro 里需要付费的高级功能做成开箱即用。

## 1. 设计原则

1. **原生优先**：SwiftUI 搭外壳，AppKit（NSTableView）承载文件列表，保证上万文件时的滚动、键盘导航、拖放与访达一致。
2. **安静的界面**：系统半透明侧边栏 + 统一工具栏；颜色只用在「当前焦点」上（活动窗格的强调色描边、选中行），其余全部是中性色。
3. **键盘可达**：所有操作都有快捷键，常用操作不超过一次按键。
4. **不打断**：文件操作在后台执行，状态栏显示进度；不弹多余的确认框（删除走废纸篓，可撤销）。

## 2. 界面布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ ● ● ●   ‹ ›  ↑     [单栏|双栏]  [列表|图标]   🔍 过滤…     ⓘ  ⋯       │  统一工具栏
├────────────┬─────────────────────────────┬───────────────────────────┤
│ 个人收藏    │ ⟨下载⟩ ⟨项目⟩ ＋             │ ⟨文稿⟩ ＋                  │  窗格内标签页
│  🏠 主目录  │ 主目录 › 项目 › Arbor        │ 主目录 › 文稿              │  面包屑路径栏
│  🖥 桌面    ├─────────────────────────────┼───────────────────────────┤
│  📄 文稿    │ 名称        修改日期  大小  │ 名称        修改日期  大小 │
│  ⬇️ 下载    │ 📁 docs     今天      --    │ ...                       │
│ 位置        │ 📄 a.swift  昨天     2 KB   │                           │
│  💽 Macintosh│ ...                        │                           │
│ 标签        ├─────────────────────────────┴───────────────────────────┤
│  🔴 红色    │ 12 项，已选 2 项（4.1 MB）              可用 120 GB      │  状态栏
└────────────┴─────────────────────────────────────────────────────────┘
                                                     └─ 可选：右侧预览检查器
```

- **窗格（Pane）**：1–3 个并排窗格，活动窗格有强调色细描边；`Tab` 键在窗格间切换焦点。
- **标签页（Tab）**：每个窗格各自拥有标签页，胶囊样式，可拖拽排序（后续）。
- **路径栏**：面包屑每一段可点击；点击空白处变为可编辑的路径输入框（支持 `~`）。
- **检查器**：右侧可收起，显示大图预览、元数据、文件夹大小。

## 4. 架构

```
Sources/Arbor/
├── App/            应用入口、菜单命令、全局设置
├── Model/          FileItem、排序、目录读取、目录监听、文件操作
├── State/          WorkspaceState → PaneState → TabState（ObservableObject）
├── Views/          SwiftUI 视图：侧边栏、窗格、标签栏、路径栏、状态栏、检查器、批量重命名
└── AppKit/         NSTableView 文件列表、Quick Look 桥接
```

- **状态树**：`WorkspaceState` 持有若干 `PaneState`，每个 `PaneState` 持有若干 `TabState`；
  `TabState` 负责一个目录：当前 URL、前进/后退栈、条目、选择、排序、过滤、视图模式。
- **数据流**：`DirectoryLoader` 在后台队列用 `FileManager.contentsOfDirectory(includingPropertiesForKeys:)`
  一次性预取资源值 → 主线程发布 `[FileItem]`；`DirectoryWatcher`（FSEvents）在变化时触发重载并保留选择。
- **文件操作**：`FileOperationQueue` 为每个拷贝/移动任务创建 `TransferEngine`（后台，`copyfile` 逐字节进度 + APFS 克隆），
  冲突通过 `ConflictResolver`（NSAlert 表单）询问；删除走 `NSWorkspace.recycle`（支持放回原处）。
- **撤销**：每个操作记录一组可逆步骤（`UndoStep.move` / `.trash`）；执行这组步骤会返回它的逆操作，因此重做无需额外代码。
- **会话**：`WorkspaceSnapshot`（Codable，基于路径）用于会话恢复与命名工作区；`WorkspaceRegistry` 在失去焦点、退出时保存。
- **构建**：Swift Package（无需 .xcodeproj），`scripts/build-app.sh` 打包为 `Arbor.app`。最低支持 macOS 14。
