# Arbor

一个兼顾美观与效率的 macOS 原生文件管理器（SwiftUI + AppKit）。设计说明见 [docs/DESIGN.md](docs/DESIGN.md)。

## 下载与安装

1. 到 [Releases](https://github.com/fancyecho/Arbor/releases) 下载最新的 `Arbor-<版本>.zip`，解压后把 `Arbor.app` 拖进「应用程序」。
2. Arbor 没有经过 Apple 公证，第一次打开会被拦下：在「系统设置 › 隐私与安全性」点「仍要打开」，或运行
   `xattr -dr com.apple.quarantine /Applications/Arbor.app`。
3. 需要 macOS 14 或更高版本。

Arbor 每天最多检查一次更新，也可以在「Arbor › 检查更新…」手动检查；设置 › 通用 › 更新 里可关闭自动检查或接收开发预览版。

## 功能

**浏览**
- 1–3 个并排窗格，各自有标签页（可固定、拖动排序、拖到另一窗格）；列表、图标、分栏、空间四种视图
- 面包屑路径栏，点空白处直接输入路径；即时过滤、递归搜索、Spotlight 搜索（支持拼音）
- 会话恢复与工作区：布局、标签页和窗口颜色存成工作区，一键切换；返回时恢复选中项和滚动位置
- 检查器：大图预览、元数据、文件夹大小、代码与 Markdown 预览和编辑

**文件操作**
- 剪切 / 拷贝 / 粘贴（与访达互通）、拷贝或移动到另一窗格，全部可撤销
- 后台操作队列（APFS 上自动克隆），同名冲突可合并、保留两者、替换或跳过
- 批量重命名（替换、正则、序号、大小写，实时预览）、按条件选择、框选
- 双窗格对比与文件夹同步，执行前预览每一步

**效率**
- ⌘K 命令面板：命令、常去文件夹（`pro arb` → …/project/Arbor）、路径补全、工作区和自定义命令
- 暂存架：从各处收集文件，再一次移动、拷贝或移到废纸篓
- 自定义 zsh 命令、外部终端和编辑器、多种格式拷贝路径、模板新建
- 40+ 个快捷键可改，右键菜单和工具栏可定制

**空间视图**（⌘4）
- 旭日图显示空间去向，可按文件夹或类型着色，点击逐层深入
- 最大文件排行、磁盘容量构成；并发扫描，主目录 73 万个文件约 30 秒
- 配合暂存架清理，移到废纸篓后图表自动更新

**工具与系统集成**
- 工具：用所选项目新建文件夹、平铺、替身、符号链接、哈希、导出目录树
- 图片：格式转换、缩放、旋转、合成 PDF、移除背景
- 访达标签与颜色规则、连接服务器（SMB / WebDAV / NFS…）
- 菜单栏图标与全局快捷键（⌃⌥Space）、访达服务、代替访达「显示文件」、显示包内容
- 中文 / English 界面

**外观**
- 窗口是一块染了工作区颜色的磨砂玻璃，侧边栏、窗格和检查器是浮在上面的卡片；macOS 26 起侧边栏、命令面板和按钮使用系统的 Liquid Glass
- 每个工作区有自己的颜色，选中、滚动条、进度都随之变化
- 开关侧边栏、增减窗格时，所有卡片沿同一条弹簧曲线一起移动
- 浅色 / 深色 / 跟随系统

压缩与解压建议交给 Keka 等专门工具。

## 从源码构建

需要 Xcode 15+，无需 .xcodeproj：

```bash
scripts/build-app.sh debug --run     # 构建 build/Arbor.app 并启动
swift test                           # 运行单元测试
scripts/release.sh                   # 打包 dist/Arbor-<版本>.zip（版本号取自 Info.plist 的 ArborReleaseTag）
swift scripts/make-icon.swift .      # 重新生成图标（需要 Xcode 的 Icon Composer）
```

浏览 `~/Library` 等受保护目录，需要在「系统设置 › 隐私与安全性 › 完全磁盘访问权限」中添加 `build/Arbor.app`。
