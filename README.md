# Arbor

一个兼顾美观与效率的 macOS 原生文件管理器（SwiftUI + AppKit）。设计说明见 [docs/DESIGN.md](docs/DESIGN.md)。

> 当前版本：**1.0**。欢迎反馈问题。

## 下载与安装

1. 到 [Releases](https://github.com/fancyecho/Arbor/releases) 下载最新的 `Arbor-<版本>.zip`，解压后把 `Arbor.app` 拖进「应用程序」。
2. Arbor 没有经过 Apple 公证（需要付费开发者账号），第一次打开会被拦下：在「系统设置 › 隐私与安全性」底部点「仍要打开」，或在终端运行
   `xattr -dr com.apple.quarantine /Applications/Arbor.app`。
3. 需要 macOS 14 或更高版本。

### 自动更新

Arbor 启动时（每天最多一次）会检查本仓库的 Releases，有新版本时显示更新说明，点「立即更新」即可下载并在重新打开后完成替换。
也可以随时在菜单「Arbor › 检查更新…」中手动检查；设置 › 通用 › 更新 里可以关闭自动检查；想抢先试用新功能，可以打开「接收开发预览版」（默认关闭）。

## 从源码构建

需要 Xcode 15+（macOS 14+）。无需 .xcodeproj：

```bash
scripts/build-app.sh debug --run     # 构建 build/Arbor.app 并启动
swift test                           # 运行单元测试
scripts/release.sh                   # 打包 dist/Arbor-<版本>.zip（版本号取自 Info.plist 的 ArborReleaseTag）
swift scripts/make-icon.swift .      # 重新生成图标
```

也可以直接用 Xcode 打开 `Package.swift` 调试。

首次访问桌面/文稿/下载时系统会请求授权；若要浏览 `~/Library` 等受保护目录，
请在「系统设置 › 隐私与安全性 › 完全磁盘访问权限」中添加 `build/Arbor.app`。

## 已实现（M1）

- 1–3 个并排窗格，每个窗格独立的标签页；活动窗格以强调色标识，`⇥` 切换
- 面包屑路径栏（点击任意层级跳转，点空白处或铅笔按钮直接输入路径，支持 `~`）
- 列表视图（NSTableView：列排序、按键选择、拖放、行内重命名）与图标视图（QuickLook 缩略图）
- 侧边栏：个人收藏、iCloud 云盘、磁盘（可推出），可拖文件到侧边栏
- 即时过滤当前文件夹、显示/隐藏隐藏文件、文件夹优先排序
- 剪切/拷贝/粘贴（与访达剪贴板互通）、复制、移到废纸篓（可「放回原处」）、新建文件夹/文本文件
- 拷贝/移动到另一窗格、拷贝路径、在终端中打开、打开方式、在访达中显示
- 批量重命名：替换（支持正则与分组）、添加前后缀、格式化序号、大小写，实时预览与冲突检测
- 检查器：大图预览、元数据、文件夹大小（后台计算）、多选汇总
- 目录变化实时刷新（FSEvents），空格快速查看

## 已实现（第一批：可靠性与日常体验）

- **撤销 / 重做**：拷贝、移动、复制、重命名、批量重命名、新建、移到废纸篓都可 ⌘Z 撤销、⇧⌘Z 重做（全应用共享，与访达一致）
- **操作队列**：拷贝/移动在后台进行，工具栏出现进度环，点开可看每个任务的进度、剩余时间并随时停止；APFS 上自动使用克隆，瞬间完成
- **冲突处理**：同名时可选 合并（文件夹）/ 保留两者 / 替换 / 跳过 / 停止，并可「对之后的冲突执行相同操作」；替换的旧文件进废纸篓，可撤销
- **会话恢复**：退出时自动保存窗格、标签页、路径、视图和排序，下次启动原样恢复（不存在的路径自动跳过）
- **工作区**：把当前布局存为工作区（⌃⌘S），在侧边栏或「工作区」菜单一键切换（⌥⌘1–9），可更新、重命名、删除
- **自定义侧边栏**：把文件夹拖到收藏的两行之间即可添加，拖动排序，右键移除或恢复默认；新增「最近」「工作区」「废纸篓」，各分组可折叠
- **标签页增强**：固定标签页（只显示图标、置顶、⌘W 不会关闭）、⇧⌘T 重新打开关闭的标签页、拖动排序、拖到另一窗格的标签栏即可移动、右键菜单（复制、移到另一窗格、关闭其他）、双击标签栏空白处新建
- **恢复现场**：返回、前进、上层或从侧边栏回到某个文件夹时，恢复离开时的选中项和滚动位置；切换标签页也会回到原来的滚动位置

## 已实现（第二批：效率核心）

- **⌘K 命令面板**：一个输入框搞定命令、文件夹跳转、路径输入、工作区和自定义命令；支持拼音与首字母（`xjwjj` → 新建文件夹）。
  智能跳转会记住常去的文件夹（访问次数 + 最近时间），`pro arb` 即可跳到 …/project/Arbor；输入 `~/` 或 `/` 可逐级补全（⇥）。⌘↩ 在新标签页打开，⌥↩ 在另一窗格打开
- **递归搜索与 Spotlight**：搜索框下方切换范围——当前文件夹 / 包含子文件夹（⌥⌘F）/ 整台 Mac（⇧⌥⌘F，可搜文件内容）；结果显示「位置」列，中文文件名可用拼音搜
- **按条件选择**（⌃⌘A）：名称（文字、通配符 `*.jpg`、正则）、类型、修改时间、大小；**选择同类型**
- **分栏视图**（⌘3）：逐级显示上层文件夹，右侧显示所选文件夹内容或文件预览；← / → 返回上层 / 进入
- **双窗格对比**（⌃⌘C）：标记两边的「仅此侧 / 较新 / 较旧 / 不同」并自动选中差异项
- **文件夹同步**（⌃⌘Y）：单向、反向或双向，可含子文件夹、可镜像删除多余项目、可比较内容哈希；执行前预览每一步，不会用旧文件覆盖新文件，全部可撤销
- **暂存架**（⌥⌘S / 右键「加入暂存架」⌥⌘A）：浮动面板，从不同地方收集文件，显示每项大小和总大小，再一次移动、拷贝到当前文件夹或全部移到废纸篓（可撤销），可拖出到其他应用
- **自定义命令**：在设置中编写 zsh 命令（`$FILES` `$FILE` `$NAMES` `$DIR`），可后台运行、显示输出或在终端中运行，出现在右键菜单和 ⌘K
- **外部应用**：设置里选择终端（终端 / iTerm / Ghostty / Warp…）和编辑器（VS Code / Cursor / Zed…），⌥⌘E 在编辑器中打开
- **拷贝路径为**：完整路径、~ 路径、带引号、终端转义、文件名、无扩展名、所在文件夹、file:// 链接

## 已实现（第三、四批：工具箱与系统集成）

- **模板新建**：右键「新建文件」或菜单「从模板新建」，模板就是 `~/Library/Application Support/Arbor/Templates` 里的文件，放入任何文件（.docx、.key…）即成为模板
- **工具**（右键 › 工具）：用所选项目新建文件夹（⌃⌘N）、平铺文件夹、制作替身、创建符号链接、计算 MD5/SHA-1/SHA-256、导出目录树——全部可撤销
- **图片**（选中图片后右键 › 图片）：转换为 JPEG/PNG/HEIC/TIFF、缩小到指定长边、向左/右旋转、合成 PDF、移除背景（Vision 抠图）
- **标签**：右键 › 标签 读写访达标签；列表与图标视图显示彩色圆点；侧边栏「标签」列出带该标签的所有文件；把文件拖到标签上即可打标签
- **颜色规则**：设置 › 颜色规则，按文件名通配符（如 `*.psd; *.ai`）给文件名着色
- **文本预览与编辑**：检查器中直接查看代码（语法着色）、Markdown 预览，点「编辑」即可修改并 ⌘S 存储（可撤销）；自动识别 UTF-8 / GB18030
- **列表列自定义**：在列表表头右键选择显示的列（修改日期、创建日期、大小、种类、扩展名、标签）
- **连接服务器**（⇧⌘K）：SMB / AFP / NFS / WebDAV / FTP，使用系统登录框与钥匙串，记住最近的服务器
- **菜单栏图标与全局快捷键**：默认 ⌃⌥Space 在任何应用中呼出 / 隐藏 Arbor（设置 › 通用中可改）
- **访达服务**：访达右键 › 服务 › 在 Arbor 中打开；也可把文件夹拖到 Dock 图标上
- **代替访达显示文件**：设置 › 通用 › 默认文件管理器。打开后，其他应用里的“在访达中显示”（浏览器下载、Raycast、Xcode……）改用 Arbor 并选中那个文件。macOS 不允许第三方应用接管“打开文件夹”本身，从聚焦搜索或 Raycast 直接打开文件夹仍是访达
- **显示包内容**：在 .app 等包上右键 ›「显示包内容」直接进入
- **自定义**：设置 › 快捷键 可改 40+ 个菜单快捷键（有冲突提示）；设置 › 右键菜单 可隐藏不用的条目；工具栏右键 › 自定义工具栏 可添加命令面板、终端、对比、同步等按钮

压缩与解压交给 Keka 等专门工具；iCloud 下载状态按需求未做。

## 外观：浮岛玻璃

- 整个窗口是一块染了工作区颜色的磨砂玻璃；侧边栏、各个窗格和检查器是浮在上面的卡片，卡片之间的缝隙可以拖动调整宽度
- 当前窗格会“浮起”：工作区颜色的描边和更深的阴影
- **布局动画**：开关侧边栏、检查器，增减窗格时，所有卡片按同一条弹簧曲线一起移动（逐帧计算，卡片和里面的列表始终同步）；放不下的列会顺着变窄的窗格平滑收起、变宽时再长出来，日期不会左右跳；新窗格从右侧展开，关闭的窗格被覆盖收起
- **外观**：设置 › 通用 › 外观，可选跟随系统 / 浅色 / 深色
- **工作区**：一组存好的窗格、标签页和颜色（例如“写论文”= 论文文件夹 + 参考文献，靛蓝色）。侧边栏「工作区」› 存储当前布局 → 起名、选色；之后点名字即可切换布局和颜色。默认自动保存：切走或退出时把当前布局存回去（设置 › 通用可关）
- **窗口颜色 = 当前工作区的颜色**：一个窗口同一时间只显示一个工作区，窗口就用它的颜色。存储工作区时可选颜色（默认挑一个还没被用过的）；打开某个工作区时窗口换成它的颜色；在侧边栏底部改颜色会立即保存到当前工作区（侧边栏里标着“当前”）。没有打开已存储的工作区时，颜色只属于这个窗口
- **列表**：选中行是一层柔和的工作区色，文字保持原色；侧边栏选中与悬停同样使用工作区色；滚动条是细长的工作区色圆条，没有灰色轨道；大小条直观显示哪个文件最占空间（超过最大文件 60% 变暖色）；修改时间旁的光点越新越亮，一小时内会发光（设置 › 通用可关闭）。窗格变窄时自动收起次要的列
- **拖放提示**：拖动文件时指针旁说明是“移动”还是“拷贝”、到哪里、按 ⌥ 会怎样
- **照片文件夹**：图标视图里，含照片的文件夹显示为磨砂玻璃文件夹，里面拼着最新的几张照片；在检查器中预览照片时，预览区背后会泛出这张照片的主色
- **进度长在标签上**：拷贝 / 移动到某个文件夹时，它的标签底部出现进度条，完成时闪一下

## 空间视图（磁盘分析）

工具栏第四个视图按钮（⌘4），或在任何文件夹 / 磁盘上右键 ›「分析空间占用」。它就是这个窗格本身的一种视图，所以返回 / 前进、路径栏、检查器、快速查看、拖放、可撤销的移到废纸篓都照常可用。

- **旭日图**：一圈圈显示文件夹里的空间去向。每一圈都有淡淡的底轨，外轮廓始终是一个完整的圆；圆角色块、内深外浅的渐变，越往外的圈只画足够大的块，不会满是碎屑。出现时一圈接一圈顺时针画出；悬停时这一块浮起并带一点同色光晕，它里面的内容亮起、其余变淡，中间显示名称、大小和占比；点文件夹就“钻”进去（扇形展开成整圆的动画），点中间回到上一层
- **两种配色**：按文件夹（以工作区颜色为起点的一圈色轮）或按类型（视频、图片、音频、文档、应用、开发、映像与虚拟机、缓存与日志）；.app 里的东西算“应用”，Caches 里的算“缓存”，node_modules / DerivedData / .git 里的算“开发”
- **类型构成条**：一眼看出这个文件夹里多少是视频、多少是缓存
- **排行列表**：「内容」按大小排列子项目，「最大的文件」直接列出整个子树里最大的 60 个文件（带所在位置），不用一层层去找；与图表联动悬停
- **整个磁盘**：容量条区分可见文件 / 系统与其他（快照、系统卷、没有权限的位置）/ 可由系统清除 / 可用；没有完全磁盘访问权限时会提示有多少文件夹没读到，并可一键打开设置
- **扫描快**：并发扫描，主目录 73 万个文件约 30 秒（系统自带的 `du` 要 59 秒）；扫描过程中图表边扫边长，完成的文件夹立刻可以点进去
- **清理篮**：在列表里悬停点「加入暂存架」（或拖过去），把要清理的东西从各处收集起来，看着总大小，一键全部移到废纸篓（⌘Z 可撤销）
- **跟着变化更新**：在 Arbor 里移到废纸篓、移动、拷贝、撤销后，图表和数字自动更新，不用重新扫描；也可以只重新扫描某个子文件夹
- **列表也受益**：扫描过的文件夹，在列表视图的「大小」列里显示真实大小和大小条，按大小排序时文件夹也参与排序
- **侧边栏**：「位置」里的每个磁盘下面有一条细细的容量条，超过 90% 变橙色
